# B站评论收藏夹

![版本](https://img.shields.io/badge/版本-1.2-00aeec)
![协议](https://img.shields.io/badge/协议-MIT-green)
![平台](https://img.shields.io/badge/平台-Chrome%20%7C%20Edge-blue)
![数据](https://img.shields.io/badge/数据-仅存本地-success)

> 一键收藏 B 站那些精辟、好笑、有用的评论。发言人、发言时间、正文、配图、点赞数、回复楼层，
> 全部完整保存下来，再配一个可以搜索、写批注、导出成 HTML / Markdown，
> 还能**自动同步到你指定的本地文件**的管理页。

**所有数据只存在你自己的电脑上，不联网、不上传、不统计。**

---

## ✨ 功能特性

### 收藏
- **一键收藏评论** —— 每条评论下方多出「仅评论」按钮，保存发言人的昵称、头像、主页链接、
  发言时间、评论正文、配图、点赞数，以及所属视频的标题和链接
- **连回复一起收藏** —— 点「评论+回复」，自动翻页抓取该评论下的**全部**回复（页面本身只显示前几条）
- **只收藏某条回复** —— 楼中楼里的某条回复也能单独收藏，并自动带上它所回复的原评论作为上下文
- **精确到秒的发言时间** —— 优先读取 B 站接口返回的时间戳；取不到时自动解析页面上的
  「刚刚 / 3分钟前 / 昨天 / 09-28」等相对时间
- **可跳回原评论** —— 每条记录都有 🔗 链接，一键跳回 B 站对应的那条评论
  （自动区分主评论和楼中楼；**BV 链接和老视频的 av 链接都支持**）

### 管理
- **本地管理页** —— 点扩展图标 → 「打开管理页面」
- **关键词搜索** —— 评论内容、发言人、视频标题、你写的点评，全都可搜
- **我的点评** —— 对主评论和每一条回复都能单独写批注，可编辑、可删除
- **回复分页折叠** —— 回复太多也不会把页面撑爆，点开才加载，每页 10 条
- **图片灯箱** —— 点击配图放大看原图，支持左右切换、长图拖动、ESC 关闭、方向键翻页

### 导出与备份
- **💾 另存为 HTML** —— 生成一个自包含的单文件网页（带搜索和图片灯箱），双击就能离线打开
- **📄 另存为 Markdown** —— 生成 `.md` 文本，方便粘进 Obsidian / 语雀 / 博客
- **📂 关联已有文件** —— 选中一个本地 HTML 文件后：
  1. 扩展会**先读取**里面的收藏，再问你是「合并」还是「用文件里的替换」——**绝不会直接覆盖**
  2. 关联成功后，之后每次增删改都会自动写进这个文件，相当于**自带实时备份**

### 「另存为」和「关联」有什么区别？

| | 💾 另存为 HTML / 📄 另存为 Markdown | 📂 关联已有文件 |
|---|---|---|
| 操作 | 弹对话框选位置，**直接写入磁盘** | 弹对话框选一个**已有文件**，读取 + 关联 |
| 会产生下载任务吗 | ❌ 不会 | ❌ 不会 |
| 之后会自动更新吗 | ❌ 只是一份**快照** | ✅ **每次改动都自动同步** |
| 会动到已有内容吗 | 文件非空时会先弹窗确认 | 先读出来问你，合并/替换/取消 |
| 能同时管几个文件 | 想存几份存几份 | 一个（换文件请先点「✂️ 取消关联」） |

> 一句话：**想留一份资料 → 「另存为」；想让某个文件一直保持最新 → 「关联已有文件」。**

## 📥 安装方法

### 方式一：下载 ZIP（推荐，最简单）

1. 点本仓库右上角绿色的 **`Code`** 按钮 → **`Download ZIP`**
2. 把下载的压缩包**解压到一个不会随便删掉的文件夹**，例如 `D:\bili-comment-saver`
   > ⚠️ 不要放在「下载」或「桌面」然后清理掉——扩展会一直引用这个位置，删了扩展就失效了
3. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
   （Edge 用户输入 `edge://extensions`）
4. 打开右上角的 **「开发者模式」** 开关
5. 点左上角 **「加载已解压的扩展程序」**，选中第 2 步解压出来的文件夹
   > 📌 选中的文件夹里应该能直接看到 `manifest.json` 这个文件。如果多套了一层文件夹（比如
   > `bili-comment-saver-main` 里面还有一个 `bili-comment-saver-main`），要选里面那一层
6. 建议点浏览器工具栏的拼图图标 🧩，把「B站评论收藏夹」**固定**到工具栏，方便随时打开

### 方式二：从 Releases 下载

到本仓库的 **Releases** 页面下载最新的 `.zip`，然后从上面的第 2 步开始操作。

## 🚀 使用方法

### 收藏评论

1. 打开任意一个 B 站视频页（网址形如 `https://www.bilibili.com/video/BV...`，
   老的 `av...` 视频页也支持）
2. 往下滚到**评论区**
3. 每条评论下方会多出两个按钮：

   | 按钮 | 作用 |
   |---|---|
   | **仅评论** | 只收藏这条主评论（快，秒存） |
   | **评论+回复** | 收藏主评论 + 它下面的**全部**回复（需要等几秒翻页） |

4. 每条回复下方还有一个单独的 **收藏** 按钮，用来只保存那一条回复
5. 按钮变成「已收藏 ✓」就成功了；「评论+回复」会显示「已收藏 N 条」

> 💡 **重要**：每次安装或更新扩展之后，都要**刷新一下已经打开的 B 站页面**（按 F5），
> 按钮才会出现。没刷新就点会提示「请刷新页面」。

### 管理收藏

点浏览器工具栏的扩展图标 → **「📋 打开管理页面」**，进去之后可以：

- 上方**搜索框**实时筛选（评论内容、发言人、视频标题、你的点评都能搜）
- 卡片右上角 **「🗑️ 删除」** 删掉这一条
- **「✏️ 添加点评」** 写下你的想法（主评论和每条回复都能单独写）
- 工具栏的 **「💾 另存为 HTML」**「**📄 另存为 Markdown**」 —— 一次性导出，不影响扩展里的数据
- 文件栏的 **「📂 关联已有文件」** —— 选一个文件后，之后所有改动都自动同步进去
  - 如果状态栏提示「**需重新授权**」，点旁边的 **「🔑 恢复写入权限」** 即可（浏览器的安全机制）
  - 想换文件或不再同步：点 **「✂️ 取消关联」**（只解除关联，**不会删你的文件**）

> 💡 **想清空全部收藏**：目前只能逐条删除，或者卸载扩展后重新安装（卸载会连数据一起删）。

## 🔒 隐私说明

**这是本项目的核心承诺：**

- ✅ 不联网、不上传、不统计、无埋点
- ✅ 收藏数据只存在浏览器本地（`chrome.storage.local`）
- ✅ 所有代码都在扩展包里，没有远程加载的脚本
- ✅ 只申请了 `storage` 和 B 站域名权限，没有 `tabs` / `cookies` / `history` / `<all_urls>`
- ✅ 导出和关联文件都是**你亲手选路径、直接写到本地磁盘**，不经过任何服务器
- ⚠️ 唯一会发网络请求的场景：点「评论+回复」时向 B 站官方接口
  `api.bilibili.com` 拉取完整回复列表（只发给 B 站自己，带登录状态是为了接口能正常返回）

完整说明请阅读 **[PRIVACY.md](PRIVACY.md)**。

## 💾 数据存在哪？怎么备份？

| 问题 | 答案 |
|---|---|
| 数据存在哪 | 你这台电脑、这个浏览器里，路径由浏览器管理（`chrome.storage.local`） |
| 换电脑还有吗 | ❌ 不会跨设备同步。但可以用「📂 关联已有文件」把之前导出的文件**读回来**（见下方常见问题） |
| 卸载扩展会怎样 | ❌ **所有收藏会被一起删除，无法恢复**。卸载前务必先备份 |
| 怎么备份 | ① 点「💾 另存为 HTML」存一份快照；② 或点「📂 关联已有文件」指定一个文件，之后它**自动跟着更新**（推荐） |
| 浏览器重装/换浏览器 | 同上，重新加载扩展后数据是空的，需要用之前导出的文件恢复 |

## ⚠️ 已知限制

1. **依赖 B 站前端页面结构**：本扩展是通过识别 B 站评论区的组件结构来插入按钮的。
   B 站一改版就可能失效，需要跟着适配。
2. **不跨设备同步**：见上一节。
3. **「评论+回复」需要等待几秒**：回复特别多（几百上千条）时要翻很多页，请耐心等按钮从
   「拉取中…」变回正常状态。
4. **可能被 B 站限流**：短时间内大量拉取回复，可能触发 B 站的频率限制，此时脚本会自动退回使用
   页面已加载的回复。
5. **数据量大时管理页会变慢**：收藏到数千条（且每条带大量回复）时，页面渲染会明显卡顿。
6. **仅支持 Chromium 内核桌面浏览器**：Chrome、Edge、Brave 等可用。
   「关联已有文件」和两个「另存为」都依赖 File System Access API，**Firefox 不支持**。
7. **关联的文件偶尔要重新授权**：浏览器出于安全考虑，重启后可能需要点一次「🔑 恢复写入权限」。
8. **没有一键清空**：只能逐条删除，或者卸载扩展（卸载会连数据一起删掉）。
9. **「另存为」不会自动更新**：它只是一份快照；想要"文件一直保持最新"，请用「📂 关联已有文件」。

## ❓ 常见问题

**Q：点收藏按钮没反应，或者提示「请刷新页面」？**
A：安装或更新扩展后，已经打开的 B 站页面必须刷新（F5）才能用。如果刷新了还不行，
去 `chrome://extensions` 点一下本扩展的刷新按钮 ⟳，再刷新 B 站页面。

**Q：评论区看不到按钮？**
A：① 确认网址是 `www.bilibili.com/video/BV...` 或 `.../video/av...` 这种视频页；
② 确认已经滚到评论区；③ 刷新页面；④ B 站可能改版了，欢迎提 Issue。

**Q：「评论+回复」收藏的条数比实际少？**
A：可能是 B 站限流或接口变动，此时会退回使用页面已经加载出来的那几条回复。
可以稍等一会儿再试。

**Q：会封号吗？**
A：扩展只**读取**页面上公开的评论，不会发评论、点赞、关注或做任何写操作。但请求过于频繁
可能触发 B 站的限流。**请勿把本工具用于大规模批量抓取。**

**Q：「另存为」和「关联已有文件」到底该用哪个？**
A：想留一份资料（备份、发给别人、导入笔记软件）→ 用「**另存为**」；
想让某个文件**一直跟着自动更新**→ 用「**关联已有文件**」。两者都只在浏览器里操作，
不会产生下载任务，也不会联网。

**Q：导出时为什么没有下载任务？**
A：因为「另存为」用的是浏览器的文件系统接口（File System Access API），你选完位置后
**直接写入磁盘**，不经过浏览器的下载系统。好处是不会在下载列表里留记录、也不会被
"下载文件夹"搞乱；代价是这个功能只在 Chrome / Edge 等 Chromium 内核浏览器上可用。

**Q：换电脑 / 重装浏览器后，收藏怎么迁回来？**
A：① 把之前导出的那份 HTML 文件拷到新电脑；② 打开管理页点「📂 关联已有文件」选中它；
③ 扩展会读出里面的收藏条数，选「**合并**」（推荐，两边都保留）或「**用文件里的替换**」
即可。这就相当于把备份导回来了。

**Q：关联文件时会把我原来的文件覆盖掉吗？**
A：**不会直接覆盖。** 扩展会先读取文件内容：
- 文件里有收藏 → 弹窗告诉你各有几条，让你选「合并 / 用文件里的替换 / 取消」
- 文件是空的 → 直接把当前收藏写进去
- 文件里没有本扩展的数据 → 单独确认一次才覆盖

**Q：导出的 HTML 文件能直接发给我朋友看吗？**
A：技术上可以，但**文件里包含其他用户的昵称、头像和主页链接**（Base64 只是编码，
不是加密，谁都能解开）。请仅用于个人备份，不要公开分享。

**Q：能不能加云同步？**
A：**不会做**，因为那意味着数据要上传服务器，与本项目的隐私承诺冲突。

## 📁 项目结构

```
bili-comment-saver/
├── manifest.json     扩展的配置文件（名称、版本、权限、入口）
├── content.js        内容脚本：在 B 站页面注入「收藏」按钮，抓取评论数据
├── inject.js         注入页面主世界的脚本：读取 B 站评论接口返回，获取精确时间与楼层关系
├── popup.html        点扩展图标后的弹出窗口（显示收藏数量）
├── popup.js          弹出窗口的逻辑
├── manage.html       管理页面界面
├── manage.js         管理页面逻辑：搜索、点评、分页、导出、本地文件关联与同步
├── icons/
│   └── icon.png      扩展图标
├── README.md         本文件
├── PRIVACY.md        隐私政策
├── LICENSE           开源协议（MIT）
└── .gitignore        防止误传导出数据的忽略规则
```

### 工作原理（简述）

```
你在 B 站看视频
      │
      ├─ inject.js  监听 B 站自己的评论接口响应 → 拿到「精确时间戳」和「谁回复了谁」
      │
      ├─ content.js 遍历评论区（含 Shadow DOM）→ 每条评论旁插入按钮
      │             点「评论+回复」时，带登录状态请求 api.bilibili.com 翻页拉全回复
      │
      └─ 数据存进 chrome.storage.local（本机）→ 不经过任何服务器
                              │
                     manage.js 读出来 → 搜索 / 写点评 / 一次性另存 / 同步到已关联的文件
```

### 想改代码？

改完 `.js` / `.html` 之后，去 `chrome://extensions` 点本扩展卡片上的**刷新按钮 ⟳**，
然后刷新 B 站页面即可生效（`manifest.json` 改动也需要这样重新加载）。
